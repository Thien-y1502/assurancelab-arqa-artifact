# ARQA v3 theory boundary

The executable object is an intersection quorum over assertion-specific domain
support sets:

`PASS iff |⋂_a D⁺(a)| >= q`.

The finite audit enumerates all `2^(5×3) = 32,768` support states and verifies
that the implementation agrees with this definition. It also checks that no
support set generated by at most one compromised domain can satisfy `q = 3`.

This is a finite consistency check, not a proof for arbitrary adaptive faults,
independent hosts, or real cryptographic key custody. The next proof gate is a
formal cut-set theorem under an explicitly stated fault model plus an
independent implementation of the checker.
